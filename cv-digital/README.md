# CV Digital - Asyqar Rafi M

Website Curriculum Vitae (CV) digital berbasis HTML5 dan CSS3. Website ini menampilkan profil pribadi, pendidikan, pengalaman, keahlian, portofolio, dan kontak dalam satu halaman yang responsif. Proyek ini dibuat untuk memenuhi Ujian Tengah Semester mata kuliah Teknologi Web, Program Studi Teknik Komputer, Universitas Bani Saleh.

## Isi Website

- **Home**: foto profil, nama, profesi, deskripsi diri, dan tombol Cetak / Unduh CV
- **About**: ringkasan latar belakang dan tujuan karier
- **Education**: riwayat pendidikan
- **Experience**: pengalaman proyek dan praktikum
- **Skills**: daftar keahlian yang dikelompokkan dalam empat bidang
- **Portfolio**: proyek yang pernah dibuat (Lembayung, GameVault, SIAGA API, Referensi Obat)
- **Contact**: alamat email, nomor telepon, GitHub, dan lokasi

## Ketentuan Teknis yang Dipenuhi

- Struktur HTML5 semantik dengan elemen header, nav, main, section, article, dan footer
- Hierarki heading yang teratur, satu h1 untuk nama dan h2 untuk setiap bagian
- Navigasi antarbagian CV dengan tautan jangkar
- External CSS pada berkas style.css
- Layout Flexbox untuk navigasi, profil, dan baris pengalaman
- CSS Grid untuk bagian Skills dan Portfolio
- Warna latar pada bagian profil, efek hover dan transition pada menu, tombol, dan kartu portofolio
- Tampilan responsif untuk layar ponsel dan mode cetak yang bersih

## Struktur Berkas

```
cv-digital/
├── index.html      Struktur dan isi halaman CV
├── style.css       Seluruh aturan tampilan
├── foto-profil.png Foto profil
└── README.md       Dokumentasi proyek
```

## Cara Menjalankan

Buka berkas `index.html` langsung di browser, atau jalankan server lokal dari folder proyek:

```
python -m http.server 8000
```

Lalu akses `http://localhost:8000` di browser.
